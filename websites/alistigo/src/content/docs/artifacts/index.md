Each artifact in this catalog is:
- **Published on npm** as a `@alistigo/artifact-*` UMD bundle, served via jsDelivr
- **Self-contained** — renders a document, handles interactions, manages persistence
- **Agent-ready** — ships with an `@alistigo/artifact-*-skill` package for Claude Code / Cursor

## Published Artifacts

### List — `@alistigo/artifact-list`

An interactive, event-sourced list widget. Supports real-time editing, checkboxes (via plugin), shared state, and AI-injectable documents.

- npm: `@alistigo/artifact-list`
- Skill: `@alistigo/artifact-list-skill`
- [Open in Playground](/app/)
