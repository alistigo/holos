The Alistigo playground is an interactive dev harness for the list artifact. It lets you
experiment with list documents, trigger commands, inspect the event log, and test plugin behavior
in real time.

**[Open Playground →](http://localhost:5173)**

The playground runs as a separate Vite dev server. Start it with:

```sh
pnpm server:start:dev   # starts playground (port 5173) + website (port 4321)
pnpm server:status      # check running processes
```
