## What is Alistigo?

Alistigo is a **framework and collection** of embeddable AI artifacts — structured, interactive UI components that run inside AI chat interfaces like Claude.

**The framework** — a set of `@alistigo/*` npm packages (`artifact-core`, `artifact-plugin-api`, `artifact-manager`, …) that give developers the building blocks to create new artifact types with a consistent quality floor.

**The catalog** — ready-to-use artifacts built with the framework (`@alistigo/artifact-list`, …), each published on npm and paired with an agent skill so any AI can drop it into a chat with a single config line.
