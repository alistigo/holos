## Steps

1. `git mv packages/alistigo-<X> packages/<new>` for each package
2. `git mv cli/alistigo-<X> cli/<new>` for each CLI
3. For npm-renamed packages: update `name` field in `package.json`
4. Update `project.json` name field (Nx project name)
5. Update `nx.json` if it references projects by name
6. `grep -r "@alistigo/domain\|@alistigo/document-format\|@alistigo/document-editor\|@alistigo/features\b" --include="*.json" --include="*.ts" --include="*.tsx" --include="*.md"` → update all hits
7. Update `pnpm-workspace.yaml` if it lists explicit paths
8. Run `pnpm install` to rebuild lockfile
9. Run `pnpm nx build:typecheck` (affected)
10. Add scope banner to `docs/domain/index.md` and all subdoc `.md` files
