# Task 52: Add AI API Simulator tab to playground

## Goal

Add an "AI API" tab to the playground that lets developers simulate AI sending API
calls to the running artifact. The tab shows available actions (from the artifact's
`api.json`), a send button per action, and a live log of calls + results.

## Files

`apps/alistigo-artifact-playground/src/`

Key existing files to understand:
- `src/components/HostPage.tsx` — main layout with existing panels/tabs
- `src/buildIframeSrcdoc.ts` — builds the iframe srcdoc HTML
- Any existing tab components

## New components / hooks

### `useApiSimulator(iframeRef, apiDefinition)`

```ts
function useApiSimulator(
  iframeRef: React.RefObject<HTMLIFrameElement>,
  apiDefinition: ArtifactApiDefinition | null
): {
  callLog: ApiCallLogEntry[];
  sendCall: (action: string, params: Record<string, unknown>) => void;
}

interface ApiCallLogEntry {
  id: string;          // unique, for React key
  timestamp: Date;
  action: string;
  params: Record<string, unknown>;
  status: "pending" | "success" | "error";
  error?: string;
}
```

**Send mechanism:** When `sendCall()` is called, inject `<api-calls>` into the live
iframe DOM (no full reload needed):

```ts
const tag = iframeRef.current.contentDocument.createElement("api-calls");
tag.textContent = JSON.stringify([{ action, params }]);
iframeRef.current.contentDocument.body.appendChild(tag);
```

This simulates the AI writing the tag. The artifact's executor will detect it, run it,
remove it, and postMessage the result back.

**Listen for results:**
```ts
window.addEventListener("message", (e) => {
  if (e.data?.type === "alistigo:api-calls-result") {
    // update callLog entries with results
  }
});
```

### `ApiSimulatorTab`

React component for the "AI API" tab content:

**Layout (two panels, stacked or side-by-side):**

**Panel 1: API Definition**
- Header: artifact name + version from the definition
- For each operation in `definition.operations`:
  - Operation name + summary
  - Param inputs (one text input per param, labeled with description)
  - "Send" button → calls `sendCall(action, params)`

**Panel 2: Call Log**
- Header: "API Call Log" + "Clear" button
- Each log entry (newest on top):
  - Timestamp (HH:MM:SS)
  - `→ actionName { param: value }`
  - Status badge: "pending" (yellow), "success" (green), "error" (red)
  - Error message if status is "error"

## Loading the API definition

The playground should load the artifact's `api.json` dynamically. Since the playground
runs in dev mode with local source:

```ts
// In HostPage.tsx or a new hook

// When selected artifact is "@alistigo/artifact-list" → use listArtifactApi
```

For now, hardcode the list artifact's API definition in the simulator (it's the only
artifact). Add a TODO comment noting this will be dynamic when more artifacts exist.
