- Package directory renames (drop `alistigo-` prefix)
- List-specific package npm name changes (add "list" to names)
- `@alistigo/artifact-core` — shared lifecycle, phases, error boundary
- `@alistigo/artifact-core-components-react` — LoadingScreen, ErrorScreen, AlistigoBadge, ArtifactInfoModal
- `@alistigo/ai-chat-async-api` — AI→artifact async API mechanism
- List artifact integrated with artifact-core
- Playground AI API Simulator tab
- Platform documentation (docs/platform/)
- Milestone reframing (M1-M6 as List Artifact milestones)

**Scope out:**
- Any new artifact type
- Auth plugin implementation
- Backend / sync / multi-user
