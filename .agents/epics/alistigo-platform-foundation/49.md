# Task 49: Scaffold @alistigo/artifact-core-components-react + Storybook

## Goal

Create the shared React UI component library for all artifacts. Ships four components
(LoadingScreen, ErrorScreen, AlistigoBadge, ArtifactInfoModal) each with a Storybook
story. This is the UI counterpart to `artifact-core`.

## Directory

`packages/artifact-core-components-react/`

Use `bash scripts/new-package.sh artifact-core-components-react` to scaffold.

## Storybook Setup

Follow the pattern in `packages/list-components-react/` (see ADR 0012). Install
`@storybook/react-vite`. Add a `storybook` target to `project.json`.

## Components

### 1. LoadingScreen

```ts
interface LoadingScreenProps {
  artifactName?: string;
}
```

- Shows the Alistigo logo from `data/img/128x128.png` (import as URL asset)
- Shows a spinner (CSS animation or Lucide icon)
- Optionally shows `artifactName` below the logo

**Logo import:** The file is at `data/img/128x128.png` relative to repo root. At build
time, use Vite's asset import: `import logoUrl from "../../data/img/128x128.png"`. The
`tsconfig.json` / `vite.config.ts` must allow PNG imports.

**Stories:** default (no name), with artifact name `"@alistigo/artifact-list"`

### 2. ErrorScreen

```ts
interface ErrorScreenProps {
  error: Error;
  onReset?: () => void;
}
```

- Shows a clear error title ("Something went wrong")
- Shows `error.message` in a code block
- If `onReset` is provided: shows a "Try again" button

**Stories:** with short error, with long error/stack trace, with reset button, without reset

### 3. AlistigoBadge

```ts
interface AlistigoBadgeProps {
  artifactName: string;
  artifactVersion: string;
  plugins: PluginInfo[];  // PluginInfo from @alistigo/artifact-core
}
```

- **Collapsed state:** small circular button (~32px) in the **top-right corner** of its
  containing element (position: absolute or fixed, top: 8px, right: 8px)
- Shows Alistigo logo inside the button
- Click: opens `ArtifactInfoModal`
- Uses a local `useState(open)` to control modal visibility

**Stories:** closed (default), open (modal visible), with errored plugin, zero plugins

### 4. ArtifactInfoModal

```ts
interface ArtifactInfoModalProps {
  open: boolean;
  onClose: () => void;
  artifactName: string;
  artifactVersion: string;
  plugins: PluginInfo[];
}
```

- Title: artifact name + version badge
- Body: list of plugins, each row:
  - Plugin name (truncated if long)
  - Version badge
  - Type chip (e.g. "storage", "analytics", "error-monitoring")
  - Status indicator: green dot (loaded), red dot with error text (error), grey (not-loaded)
- If `plugins` is empty: "No plugins configured" message
- Close button

**Stories:** all loaded, one errored plugin, zero plugins

## Styling

Tailwind v4 — follow the pattern in `packages/list-components-react/`. Add `tailwind.config.ts`
if needed (or use the CSS-import pattern if v4 auto-detects). Use Radix Colors for status
colors (green-9 for loaded, red-9 for error, gray-9 for not-loaded).
