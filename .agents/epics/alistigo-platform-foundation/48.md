# Task 48: Scaffold @alistigo/artifact-core

## Goal

Create the shared lifecycle engine used by every artifact. This package is the foundation
that every future `@alistigo` artifact depends on instead of reimplementing loading,
error capture, and plugin orchestration from scratch.

## Directory

`packages/artifact-core/`

Use `bash scripts/new-package.sh artifact-core` to scaffold, then add the implementation.

## Exports

### Types

```ts
// Lifecycle phases every artifact transitions through
export type ArtifactPhase = "loading" | "ready" | "error";

// Context available to artifact-core consumers
export interface ArtifactContext {
  phase: ArtifactPhase;
  error?: Error;
  plugins: LoadedPlugin[];
}

// Loaded plugin descriptor (passed to AlistigoBadge)
export interface LoadedPlugin {
  name: string;
  version: string;
  type: string;
  status: "loaded" | "error" | "not-loaded";
  error?: string;
}

// @experimental — placeholder for future auth plugin type
export interface AuthPlugin {
  readonly _brand: "AuthPlugin";
}
```

### ArtifactLifecycle (class or React context)

Manages phase transitions. Wraps `React.createContext`. Provides:
- `transitionTo(phase: ArtifactPhase, error?: Error): void`

### startArtifact()

```ts
export async function startArtifact(config: {
  plugins: PluginSpec[];
  onPhaseChange: (phase: ArtifactPhase, ctx: ArtifactContext) => void;
}): Promise<ArtifactContext>;
```

Runs the standard startup sequence:
1. Emit `"loading"` phase
2. Load plugins via `@alistigo/artifact-plugin-api`'s `loadPlugins()`
3. Resolve active storage (if storage plugins present)
4. Emit `"ready"` phase with loaded plugin list
5. On any unhandled error → emit `"error"` phase

### ArtifactErrorBoundary

React class component extracted from `artifact-list`'s current `ArtifactErrorBoundary`:
```ts

```
On `componentDidCatch`: emits `error:uncaught` on plugin bus + calls `onError` prop.
