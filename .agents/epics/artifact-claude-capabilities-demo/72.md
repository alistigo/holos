# Task: AI tab — window.claude.complete

## Description

Implement `AiTab.tsx`: a text input + button that calls `window.claude.complete(prompt)` and displays a running history of requests with pending / error / result states.

## Acceptance Criteria

- [ ] Textarea for entering a prompt, "Ask Claude" button to submit
- [ ] Submitting adds a `pending` entry to the request history list
- [ ] The entry resolves to `result` (showing Claude's response text) on success
- [ ] The entry resolves to `error` (showing the error message in red) on failure
- [ ] Multiple requests can be submitted without waiting (non-blocking)
- [ ] Pending entries show a spinner
- [ ] Textarea clears after submit
- [ ] Works in draft mode (no storage dependency)

## Technical Details

### State shape

```typescript
type RequestStatus = 'pending' | 'error' | 'result';

interface RequestEntry {
  id: string;
  prompt: string;
  status: RequestStatus;
  response?: string;
  error?: string;
  createdAt: Date;
}
```

### API call

```typescript
import { claudeApi } from "@alistigo/claude-artifact-api";
// or directly:
const response = await (window as Window & { claude?: { complete: (p: string) => Promise<string> } }).claude?.complete(prompt);
```

Check `@alistigo/claude-artifact-api` for the typed `window.claude.complete` accessor to avoid casting.

### History list rendering

- Most recent entry at the top
- `pending`: grey row with animated spinner + truncated prompt
- `error`: red row with error message
- `result`: white/light row with full response (scrollable, max-height)
