# Task: Deprecate old npm packages — manual post-publish step

## Description

After the new packages (`@alistigo/artifact-claude-capabilities-demo` and `@alistigo/artifact-claude-capabilities-demo-skill`) are published to npm, mark the old package names as deprecated with a forwarding message. This is a manual step requiring npm publish credentials.

## Acceptance Criteria

- [ ] `@alistigo/artifact-storage-explorer` shows a deprecation warning on npm
- [ ] `@alistigo/artifact-storage-explorer-skill` shows a deprecation warning on npm
- [ ] Both warnings include the new package name

## Technical Details

Run after publishing the new packages:

```sh
npm deprecate @alistigo/artifact-storage-explorer "Renamed to @alistigo/artifact-claude-capabilities-demo. Please update your dependency."
npm deprecate @alistigo/artifact-storage-explorer-skill "Renamed to @alistigo/artifact-claude-capabilities-demo-skill. Please update your dependency."
```

Verify:
```sh
npm info @alistigo/artifact-storage-explorer | grep deprecated
npm info @alistigo/artifact-storage-explorer-skill | grep deprecated
```

Note: `npm deprecate` requires being logged in as a package maintainer. The old package versions remain downloadable — they are not removed.
