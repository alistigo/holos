# Task: External Navigation tab — links + window.open

## Description

Implement `ExternalNavigationTab.tsx`: demonstrates how `<a>` link clicks and `window.open()` are intercepted by the inject-script and routed through the parent frame (since the sandboxed iframe cannot open external URLs itself).

## Acceptance Criteria

- [ ] A curated list of `<a>` links with `target="_blank"` and `rel="noopener noreferrer"`
- [ ] Each link includes the site name and URL displayed
- [ ] An explanatory note: "Links open via the parent frame — the artifact's sandbox prevents direct navigation"
- [ ] A `window.open()` demo form: URL text input + "Open in new tab" button
- [ ] Clicking "Open in new tab" calls `window.open(url)` and shows a brief confirmation ("Requested parent to open: <url>")
- [ ] Works in draft mode

## Technical Details

### Curated link list

```tsx
const LINKS = [
  { label: "MDN Web Docs", url: "https://developer.mozilla.org" },

];
```

Render as a `<ul>` with `<li><a href={url} target="_blank" rel="noopener noreferrer">{label}</a> <span className="text-xs text-gray-400">{url}</span></li>`.

### Explanation

Two explanatory boxes:
1. Above the link list: how `<a>` link interception works (inject-script routes external links to parent via `openExternal` postMessage)
2. Above the window.open form: how `window.open()` is overridden to send `openExternal` to parent

### window.open form

```typescript
function handleOpen(url: string): void {
  window.open(url);
  setLastOpened(url);
}
```

Show: "Requested parent to open: https://..." below the button after click.
