# Task: API Calls tab — window.fetch proxy

## Description

Implement `ApiCallsTab.tsx`: a form for building HTTP requests + a call history list, demonstrating the `window.fetch` override that proxies requests through the Claude parent frame.

## Acceptance Criteria

- [ ] Form fields: URL (text input, pre-filled with `https://httpbin.org/get`), Method (select: GET / POST / PUT / DELETE / PATCH)
- [ ] Headers section: add/remove key-value pairs; starts empty
- [ ] Body section: textarea, shown only when method is POST / PUT / PATCH
- [ ] "Send Request" button submits the call
- [ ] Submitting adds a `pending` entry to the call history
- [ ] Entry resolves to `result` with HTTP status code + response body (truncated to ~500 chars)
- [ ] Entry resolves to `error` with the error message on network failure
- [ ] Multiple calls can be in flight simultaneously
- [ ] Works in draft mode

## Technical Details

### State shape

```typescript
type CallStatus = 'pending' | 'error' | 'result';

interface CallEntry {
  id: string;
  url: string;
  method: string;
  status: CallStatus;
  statusCode?: number;
  responseText?: string;
  error?: string;
  createdAt: Date;
}
```

### Fetch implementation

```typescript
async function makeCall(entry: CallEntry, headers: Record<string, string>, body?: string): Promise<void> {
  try {
    const res = await fetch(entry.url, {
      method: entry.method,
      headers,
      body: ['POST', 'PUT', 'PATCH'].includes(entry.method) ? body : undefined,
    });
    const text = await res.text();
    // update entry: status = 'result', statusCode = res.status, responseText = text.slice(0, 500)
  } catch (err) {
    // update entry: status = 'error', error = String(err)
  }
}
```

`window.fetch` is overridden by the inject-script to proxy requests through the parent frame via postMessage.

### Headers UI

Start with 0 rows. "+ Add header" button appends an empty key-value row. Each row has a remove button.

### Call history

Most recent at top. Show: method badge + URL + status. Expand on click to show full response.
