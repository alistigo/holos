# Task: File Generation tab — URL.createObjectURL download

## Description

Implement `FileGenerationTab.tsx`: a JSON textarea editor + "Download JSON" button that demonstrates the `URL.createObjectURL` override and Claude's file download mechanism.

## Acceptance Criteria

- [ ] Textarea pre-seeded with pretty-printed sample JSON
- [ ] JSON is validated on every change; invalid JSON shows an inline error
- [ ] "Download JSON" button is disabled while JSON is invalid
- [ ] Clicking "Download JSON" triggers a file download named `export.json`
- [ ] The download mechanism uses `URL.createObjectURL` → the inject-script intercepts the `blob-request://` URL and asks the parent to trigger the real download
- [ ] A brief explanation of the mechanism is shown below the editor
- [ ] Works in draft mode

## Technical Details

### Sample JSON seed

```json
{
  "message": "Hello from a Claude artifact!",
  "timestamp": "<ISO timestamp>",
  "api": "URL.createObjectURL"
}
```

Seed the timestamp dynamically on component mount.

### Download implementation

```typescript
function downloadJson(jsonText: string): void {
  const blob = new Blob([jsonText], { type: "application/json" });
  const url = URL.createObjectURL(blob); // returns blob-request://... in artifact
  const a = document.createElement("a");
  a.href = url;
  a.download = "export.json";
  document.body.appendChild(a);
  a.click();
  document.body.removeChild(a);
  URL.revokeObjectURL(url);
}
```

The inject-script click listener intercepts `blob-request://` links, resolves the stored blob, and posts a download request to the parent frame.

### Explanation callout

A small info box below the button explaining:
> "In a normal browser, `URL.createObjectURL` returns a `blob:` URL. Inside a Claude artifact, it's overridden to return a `blob-request://` token. Clicking a link with this href triggers the parent frame to download the file on your behalf."
