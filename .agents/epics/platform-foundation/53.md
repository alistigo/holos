### `docs/platform/artifact-contract.md`

What every `@alistigo` artifact must implement:

1. **Lifecycle phases** — loading → ready | error (via `artifact-core`)
2. **Config-doc + State-doc contract** (already in architecture.md §12 — link to it)
3. **Loading screen** — shown during loading phase (via `artifact-core-components-react`)
4. **Error screen** — shown on uncaught error (via `artifact-core-components-react`)
5. **Alistigo badge** — top-right corner, shows artifact info + plugin list (via `artifact-core-components-react`)
6. **Plugin hook** — integrates with `@alistigo/artifact-plugin-api`
7. **AI async API** — registers actions via `@alistigo/ai-chat-async-api`, publishes `api.json`
8. **Agent skill** — ships a skill package teaching AI when/how/what to use the artifact

For each item: brief description, which package implements it, example code snippet.

### `docs/platform/skill-pattern.md`

How each artifact publishes an agent skill:

- Skill package: `packages/artifact-<name>-skill/` (e.g. `artifact-list-skill`)
- Skill file: `SKILL.md` at root of skill package
- What the skill must teach:
  1. **What** the artifact is (1-paragraph description)
  2. **When** to use it (trigger phrases, use-cases)
  3. **Config** — how to write the config document (fields, defaults, example)
  4. **API** — how to use the AI async API (available actions, params, example `<api-calls>` tag)
- Reference: existing `packages/artifact-list-skill/SKILL.md` as the canonical example
- Skill registration: follows agentskills.io standard (ADR 0015)

### `docs/platform/plugin-types.md`

Taxonomy of plugin types in the Alistigo platform:

| Type | Purpose | Examples | Interface field |
|------|---------|---------|-----------------|
| infra | Lifecycle monitoring, analytics | sentry-plugin, posthog-plugin | `setup()`, `mounted()`, event bus |
| domain | Data shape extensions, render contributions | checkbox-element (M3) | `dataShape`, `render`, `commands`, `events` |
| storage | Document persistence backends | claude-storage-plugin, local-storage-plugin | `isAvailable()`, `createStore()` |
| auth | User authentication + identity | (planned — no implementation in P0) | `@experimental AuthPlugin` in artifact-core |

Note: each artifact skill is technically a separate package, not a plugin. Distinguish clearly.
