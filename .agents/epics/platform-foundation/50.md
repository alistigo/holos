# Task 50: Integrate artifact-core into the list artifact

## Goal

Update `@alistigo/artifact-list` to use `@alistigo/artifact-core` and
`@alistigo/artifact-core-components-react`. Replace its own loading/error boundary code
with shared platform code. Show LoadingScreen during plugin loading, ErrorScreen on
uncaught errors, and render AlistigoBadge in the top-right corner when ready.

## Files to modify

`packages/artifact-list/src/` (after Task 46 rename)

- `mount.ts` — main integration point
- `components/App.tsx` — add AlistigoBadge overlay
- `package.json` — add new deps

## Changes

### 1. Add dependencies

In `packages/artifact-list/package.json`:
```json
"@alistigo/artifact-core": "workspace:*",
"@alistigo/artifact-core-components-react": "workspace:*"
```

### 2. Replace ArtifactErrorBoundary

Remove the existing `ArtifactErrorBoundary` class from `mount.ts`. Import and use
`ArtifactErrorBoundary` from `@alistigo/artifact-core`.

### 3. Replace loading phase logic

Current `mount.ts` loads plugins, then renders. Wrap this in `startArtifact()`:

```tsx
// pseudo-code — adapt to actual mount.ts structure
const ctx = await startArtifact({
  plugins: buildPluginSpec(config),
  onPhaseChange: (phase, ctx) => {
    if (phase === "loading") renderApp(<LoadingScreen artifactName="@alistigo/artifact-list" />);
    if (phase === "error")   renderApp(<ErrorScreen error={ctx.error!} />);
    if (phase === "ready")   renderApp(<MainApp ctx={ctx} />);
  },
});
```

### 4. Add AlistigoBadge

In `components/App.tsx` (the "ready" phase renderer), wrap the existing list UI:

```tsx
import { AlistigoBadge } from "@alistigo/artifact-core-components-react";

export function App({ ctx }: { ctx: ArtifactContext }) {
  return (
    <div style={{ position: "relative", height: "100%", width: "100%" }}>
      <ListBody />
      <AlistigoBadge
        artifactName={ARTIFACT_NAME}    // injected by Vite define
        artifactVersion={ARTIFACT_VERSION}
        plugins={ctx.plugins}
      />
    </div>
  );
}
```

`ARTIFACT_NAME` and `ARTIFACT_VERSION` are injected at build time via Vite `define` in
`vite.config.ts` (read from `package.json` via `JSON.parse(readFileSync(...))`).

### 5. Remove extracted code from artifact-list

After confirming that `artifact-core` provides the equivalents:
- Remove `ArtifactErrorBoundary` class from `mount.ts`
- Remove any manual "loading" render path if it existed
