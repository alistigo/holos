# Task 51: Scaffold @alistigo/ai-chat-async-api

## Goal

Create the library that allows AI chat to call actions on a running artifact, by writing
a specific `<api-calls>` HTML tag. The artifact detects the tag on boot, executes the
calls, and removes the tag. AI is fire-and-forget — no response mechanism for the AI,
but the artifact emits a postMessage for the playground's call log.

## Background / Innovation

AI chat cannot use postMessage directly, but it CAN write HTML. We exploit this: AI
writes `<api-calls>[...]</api-calls>` into the artifact's HTML. On boot, the artifact
reads and executes the calls, then removes the tag. This gives AI a defined, safe API
without exposing an arbitrary code execution surface.

The format is based on an AsyncAPI 3.0 subset: each artifact publishes an `api.json`
describing its operations. The playground reads this to show available actions.

## Directory

`packages/ai-chat-async-api/`

Use `bash scripts/new-package.sh ai-chat-async-api` to scaffold.

## The `<api-calls>` tag format

```html
<api-calls>
[
  { "action": "addElement", "params": { "text": "Buy milk" } },
  { "action": "addElement", "params": { "text": "Buy eggs" } },
  { "action": "renameList", "params": { "name": "Grocery list" } }
]
</api-calls>
```

Rules:
- Tag content is a JSON array of `{ action: string, params: Record<string, unknown> }`
- Actions execute in order
- If an action fails: log the error, continue to next (partial execution)
- After all actions (success or failure): remove the `<api-calls>` tag from the DOM
- Emit `parent.postMessage({ type: "alistigo:api-calls-result", results: [...] })` with
  per-call status

## AsyncAPI-subset format for ArtifactApiDefinition

Research AsyncAPI 3.0 (https://www.asyncapi.com/docs/reference/specification/v3.0.0).
We adopt a minimal subset:

```ts
interface ArtifactApiDefinition {
  info: {
    title: string;       // artifact display name
    version: string;     // artifact version
    description?: string;
  };
  operations: Record<string, ApiOperation>;
}

interface ApiOperation {
  summary: string;
  description?: string;
  params?: Record<string, JsonSchemaProperty>;  // JSON Schema properties for params object
  required?: string[];  // required param names
}
```

Store as `api.json` in each artifact package. Export TypeScript type + a `validateApiCall()`
utility.

## Exports

```ts
// Core executor
export class ApiCallsExecutor {
  constructor(
    definition: ArtifactApiDefinition,
    handlers: Record<string, ApiActionHandler>
  );
  run(): Promise<ApiCallResult[]>;  // reads <api-calls> tag, executes, removes tag
}

// React hook integration
export function useApiCallsExecutor(
  definition: ArtifactApiDefinition,
  handlers: Record<string, ApiActionHandler>
): void;  // runs once on mount

// Builder helper
export function defineApiAction(
  name: string,
  handler: ApiActionHandler
): { name: string; handler: ApiActionHandler };

// Types
export type ArtifactApiDefinition = { ... };
export type ApiOperation = { ... };
export type ApiActionHandler = (params: Record<string, unknown>) => Promise<void> | void;
export type ApiCallResult = {
  action: string;
  status: "success" | "error";
  error?: string;
};
```

## List artifact API definition (reference)

Create `packages/artifact-list/api.json`:
```json
{
  "info": {
    "title": "Alistigo List Artifact API",
    "version": "0.1.0",
    "description": "AI-callable actions for the @alistigo/artifact-list artifact"
  },
  "operations": {
    "addElement": {
      "summary": "Add an element to the list",
      "params": {
        "text": { "type": "string", "description": "Text content of the element" }
      },
      "required": ["text"]
    },
    "deleteElement": {
      "summary": "Delete an element by ID",
      "params": {
        "id": { "type": "string", "description": "Element ID to delete" }
      },
      "required": ["id"]
    },
    "renameList": {
      "summary": "Rename the list",
      "params": {
        "name": { "type": "string", "description": "New list name" }
      },
      "required": ["name"]
    },
    "clearList": {
      "summary": "Remove all elements from the list",
      "params": {}
    }
  }
}
```

Export the definition from `packages/artifact-list/src/index.tsx`:
```ts
export { default as listArtifactApi } from "../api.json";
```

after the "ready" phase is reached (before signaling mounted). This is wired in Task 50.
