# Task 45: ADR 0018 — Alistigo as a Platform for AI Artifacts

## Goal

Write and commit ADR 0018 capturing the scope change: Alistigo is a platform for AI

## ADR content to cover

**Status:** Accepted  
**Date:** 2026-07-27

**Context:**
- M1 + M2 shipped a list app with a plugin system and playground
- Planning for M3+ revealed that all shared infra (loading, error handling, badge, AI
  API) would need to be duplicated for every future artifact
- Package names like `alistigo-domain` and `alistigo-document-format` imply
  platform-level scope but are entirely list-specific
- The `alistigo-` directory prefix adds noise since the whole repo is alistigo

**Decision:**
- Alistigo is a platform for AI artifacts; list is the reference implementation
- Platform layer diagram (4-tier: Dev Tools → Artifacts → Artifact Core → Platform Infra)
- Artifact contract: every artifact implements loading phases, plugin hook, AI async API,
  config-doc + state-doc, Alistigo badge (top-right), and an agent skill
- Skill pattern: each artifact ships a skill teaching AI (what/when/config/API)
- Plugin type taxonomy: infra, domain, storage, auth (planned), per-artifact skill
- Naming convention: platform packages are generic; list-specific packages carry "list"
- Directory rename: drop `alistigo-` prefix from all `packages/` and `cli/` dirs

**Consequences:**
- Package directory renames (tracked in Task 46)
- Three new shared libraries: artifact-core, artifact-core-components-react, ai-chat-async-api
- Playground gains AI API Simulator tab
- M1-M6 milestones become "List Artifact Milestones"; P0 is the Platform Foundation milestone

Include the full platform layer diagram in the ADR.
