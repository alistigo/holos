# Task: Extend plugin API with type system and storage interface

## Description

Extend `@alistigo/artifact-plugin-api` to introduce two new concepts:
1. A `type` field on `AlistigoPlugin` for categorizing plugins by role ("monitoring", "storage", etc.)
2. An `AlistigoStorageExtension` interface that storage plugins attach to via `plugin.storage`

This is the foundation task — tasks 002 and 003 cannot start until this is merged.

## Acceptance Criteria
- [ ] `PluginType = "monitoring" | "storage" | (string & {})` is exported from the package
- [ ] `AlistigoStorageExtension` is exported with `isAvailable()`, `createStore()`, `listKeys()`, and optional `seedIfEmpty()`
- [ ] `AlistigoPlugin.type?: PluginType` is added
- [ ] `AlistigoPlugin.storage?: AlistigoStorageExtension` is added
- [ ] No existing plugin tests break (all fields are optional — backwards compat)
- [ ] Package typechecks cleanly

## Technical Details

**File: `packages/alistigo-artifact-plugin-api/src/types.ts`**

Add after the existing imports:
```typescript
import type { AlistigoListStore } from "@alistigo/document-editor";
import type { AlistigoDocument } from "@alistigo/document-format";

export type PluginType = "monitoring" | "storage" | (string & {});

export interface AlistigoStorageExtension {
  /** Returns true if this storage backend is available in the current runtime context. */
  isAvailable(): boolean;
  /** Instantiates and returns the concrete AlistigoListStore. Called once per mount. */
  createStore(): AlistigoListStore;
  /**
   * Lists key-value pairs from this storage, optionally filtered by prefix.
   * Used by the playground host to inspect storage contents.
   */
  listKeys(prefix?: string): Promise<Array<{ key: string; value: string }>>;
  /**
   * Seeds the store with `doc` if no data exists for that list ID.
   * Optional — only local storage needs this; Claude storage does not.
   */
  seedIfEmpty?(doc: AlistigoDocument): Promise<void>;
}
```

Add to `AlistigoPlugin`:
```typescript
/** Plugin category — informational, enables type-based queries by the host. */
type?: PluginType;
/** Present when type === "storage". Provides the storage backend contract. */
storage?: AlistigoStorageExtension;
```

**File: `packages/alistigo-artifact-plugin-api/src/index.ts`**

Add to exports:

```typescript
export type { PluginType, AlistigoStorageExtension } from "./types.js";
```
