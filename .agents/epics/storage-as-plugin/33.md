# Task: Create alistigo-local-storage-plugin

## Description

Rename `alistigo-local-storage-repository` → `alistigo-local-storage-plugin` and refactor it into a full `AlistigoPlugin` implementation with `type: "storage"` and the `storage` extension. Retain `LocalStorageListRepository` as a named export for internal use and backwards compatibility.

## Acceptance Criteria
- [ ] Directory renamed from `packages/alistigo-local-storage-repository` to `packages/alistigo-local-storage-plugin`
- [ ] npm package name is `@alistigo/local-storage-plugin`
- [ ] Nx project name is `alistigo-local-storage-plugin`
- [ ] `localStoragePlugin` exported as default implements `AlistigoPlugin` with `type: "storage"`
- [ ] `storage.isAvailable()` performs a write probe and catches SecurityError
- [ ] `storage.createStore()` returns `new LocalStorageListRepository()`

- [ ] Vite build produces a self-contained ESM bundle (no bare imports — same pattern as Sentry/PostHog plugins)
- [ ] Package typechecks and builds cleanly

**Step 4 — New file `src/local-storage-plugin.ts`:**
```typescript
import type { AlistigoPlugin } from "@alistigo/artifact-plugin-api";
import { LocalStorageListRepository } from "./local-storage-list-repository.js";

const localStoragePlugin: AlistigoPlugin = {
  name: "@alistigo/local-storage-plugin",
  type: "storage",
  storage: {
    isAvailable(): boolean {
      try {
        localStorage.setItem("__alistigo_probe__", "1");
        localStorage.removeItem("__alistigo_probe__");
        return true;
      } catch {
        return false;
      }
    },
    createStore() {
      return new LocalStorageListRepository();
    },
    async listKeys(prefix = ""): Promise<Array<{ key: string; value: string }>> {
      return Object.entries(localStorage)
        .filter(([k]) => k.startsWith(prefix))
        .map(([key, value]) => ({ key, value }));
    },
    async seedIfEmpty(doc) {
      await new LocalStorageListRepository().seedIfEmpty(doc);
    },
  },
};

export default localStoragePlugin;
```
