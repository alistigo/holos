# Task: Cleanup stale references to old package names

## Description

After tasks 002 and 003 rename the packages, audit all source files and configuration for any remaining references to the old names (`local-storage-repository`, `claude-artifact-list-storage`) and fix them. Run `nx reset` to flush the Nx project graph cache.

## Acceptance Criteria
- [ ] Zero occurrences of `local-storage-repository` in `packages/` or `apps/` source files
- [ ] Zero occurrences of `claude-artifact-list-storage` in `packages/` or `apps/` source files
- [ ] `pnpm nx reset` has been run to flush stale project graph cache
- [ ] `pnpm nx affected -t build` completes without errors

## Technical Details

**Audit command:**
```bash
grep -r "local-storage-repository\|claude-artifact-list-storage" \
  packages/ apps/ \
  --include="*.ts" --include="*.tsx" --include="*.json" --include="*.md" \
  -l
```

Expected files to check and fix (if still referencing old names after tasks 002+003):
- Any remaining `package.json` files with old dep names
- Any `project.json` files
- Any import strings (should be caught by T4 but verify)
- Any doc references in `packages/*/README.md` if they exist

**After fixing:**
```bash
pnpm nx reset
```

## Dependencies
- Task 002 and 003 must be complete (packages renamed)
