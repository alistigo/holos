# Task: Update artifact-list to use storage plugins via CDN

## Description

Remove hardcoded storage selection from `App.tsx` and integrate storage plugins into the existing CDN loading mechanism. `mount()` will inject default storage plugin names at the front of the spec, resolve the active store after plugin loading, and pass it to `App.tsx` as a prop. Add an in-memory fallback store.

## Acceptance Criteria
- [ ] `App.tsx` has zero imports from `@alistigo/local-storage-repository` or `@alistigo/claude-artifact-list-storage` or their renamed equivalents
- [ ] `App.tsx` accepts `repository: AlistigoListStore` as a prop and calls `repository.seedIfEmpty?.(initialDocument)` duck-typed

- [ ] `packages/alistigo-artifact-list/package.json` no longer depends on the old storage packages
- [ ] All existing tests pass

## Technical Details

**New file `src/utils/in-memory-store.ts`:**
```typescript
import type { AlistigoListStore } from "@alistigo/core-document-editor";
import type { AlistigoDocument } from "@alistigo/core-document-format";
import type { List, ListId } from "@alistigo/domain";
import { ListDocumentSerializer } from "@alistigo/core-document-format";

export class InMemoryListStore implements AlistigoListStore {
  private readonly docs = new Map<string, AlistigoDocument>();

  async load(id: ListId): Promise<List | undefined> {
    const doc = this.docs.get(id.toString());
    return doc ? ListDocumentSerializer.deserialize(doc) : undefined;
  }

  async save(list: List): Promise<void> {
    const prev = await this.loadDocument(list.id);
    this.docs.set(list.id.toString(), ListDocumentSerializer.serialize(list, prev));
  }

  async loadDocument(id: ListId): Promise<AlistigoDocument | undefined> {
    return this.docs.get(id.toString());
  }
}
```

**Update `src/plugins.ts`:**

Add to the file:
```typescript
import type { AlistigoPlugin } from "@alistigo/artifact-plugin-api";

const DEFAULT_STORAGE_PLUGINS: Record<string, Record<string, unknown>> = {
  "@alistigo/claude-storage-plugin": {},
  "@alistigo/local-storage-plugin": {},
};

/** Builds the effective plugin spec: default storage plugins at front, user plugins after. */
export function buildPluginSpec(
  userSpec: Record<string, Record<string, unknown>> | undefined,
): Record<string, Record<string, unknown>> {
  const user = userSpec ?? {};
  const result: Record<string, Record<string, unknown>> = {};
  for (const [k, v] of Object.entries(DEFAULT_STORAGE_PLUGINS)) {
    if (!(k in user)) result[k] = v;
  }
  Object.assign(result, user);
  return result;
}
```

**Update `src/mount.ts`:**

Add `resolveStore()` helper:
```typescript
import type { AlistigoListStore } from "@alistigo/core-document-editor";
import { InMemoryListStore } from "./utils/in-memory-store.js";

function resolveStore(plugins: AlistigoPlugin[]): AlistigoListStore {
  for (const p of plugins) {
    if (p.type === "storage" && p.storage?.isAvailable()) {
      return p.storage.createStore();
    }
  }
  log.info({}, "no storage plugin available — using in-memory store");
  return new InMemoryListStore();
}

function detectStorageType(plugins: AlistigoPlugin[]): string {
  const active = plugins.find((p) => p.type === "storage" && p.storage?.isAvailable());
  return active?.name ?? "none";
}
```
