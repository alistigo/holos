# Task: Shared-List View — Projection Layer

## Description

Extend the `AlistigoProjection` type and its builder to include per-element actor attribution. Attribution is derived from the event log + the `alistigo:actors` section of the document.

This task also adds `date-fns` to the `list-components-react` package so the UI can format relative dates.

## Acceptance Criteria
- [ ] `AlistigoProjection` item type has an optional `alistigo:attribution?` field: `{ actorId: string; pseudo: string; avatar: string; addedAt: string }` (ISO timestamp)
- [ ] Attribution is populated by scanning the event log: for each element, find the first `ListElementAdded` event with that `listElementId`, then look up the actor in `alistigo:actors`
- [ ] Attribution is set to `undefined` when the actor is not found in `alistigo:actors` (defensive — actor may be non-user)
- [ ] `date-fns` is added to `packages/list-components-react/package.json` dependencies
- [ ] Existing projection tests still pass
- [ ] New tests cover: attribution populated for known actor, attribution absent when actor not in actors section, attribution absent when only one user actor

## Technical Details

**First: find where `AlistigoProjection` is defined.**
It is imported from `@alistigo/list-document-format` in the stories. Search the package for `AlistigoProjection` — it may be in a `projection.ts` file or re-exported from a sub-path. If it does not yet exist as a formal type, infer it from the story shapes and define it in `packages/list-document-format/src/projection.ts`, export it from `index.ts`.

**Projection item attribution shape:**
```typescript
interface AlistigoItemAttribution {
  actorId: string;
  pseudo: string;
  avatar: string;   // base64 data URL
  addedAt: string;  // ISO 8601 timestamp from the ListElementAdded event
}
```

**Derivation logic:**
```typescript
function buildAttributionMap(doc: AlistigoDocument): Map<string, AlistigoItemAttribution> {
  const actorsById = new Map(
    (doc["alistigo:actors"] ?? []).map(a => [a["alistigo:actorId"], a])
  );
  const result = new Map<string, AlistigoItemAttribution>();
  for (const event of doc["alistigo:listEventLog"]) {
    if (event["alistigo:eventType"] === "ListElementAdded") {
      const elementId = event["alistigo:listElementId"];
      if (!result.has(elementId)) {
        const actor = actorsById.get(event["alistigo:actorId"]);
        if (actor) {
          result.set(elementId, {
            actorId: actor["alistigo:actorId"],
            pseudo: actor["alistigo:pseudo"],
            avatar: actor["alistigo:avatar"],
            addedAt: event["alistigo:timestamp"],
          });
        }
      }
    }
  }
  return result;
}
```

The projection builder calls this when `alistigo:actors` is present and has ≥2 entries.
