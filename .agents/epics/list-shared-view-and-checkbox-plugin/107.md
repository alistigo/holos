# Task: artifact-plugin-api — Domain-Contribution Extension

## Description

Add the domain-contribution plugin contract to `AlistigoPlugin` in `packages/artifact-plugin-api/src/types.ts`. This replaces the opaque `dataShape`, `render`, `commands`, `events` stubs with a concrete typed contract that the checkbox plugin (task 006) will implement and the ListView (task 007) will consume.

## Acceptance Criteria
- [ ] `AlistigoPlugin` has `metadataKey?: string` — the plugin's key in `alistigo:metadatas`
- [ ] `AlistigoPlugin` has `metadataSchema?: unknown` — JSON schema fragment (informational)
- [ ] `AlistigoPlugin` has `reduce?: (elementMetadata: Record<string, unknown>, event: AlistigoEventRecord) => Record<string, unknown>` — pure reducer
- [ ] `AlistigoPlugin` has `renderListElementLeading?: (elementId: string, metadata: Record<string, unknown>, onCommand: (name: string, payload: unknown) => void) => ReactNode` — leading UI slot
- [ ] Old opaque stubs (`dataShape`, `render`, `commands`, `events`) are **removed** (they were only forward-compat placeholders, no production code reads them)
- [ ] The type `AlistigoEventRecord` is imported from `@alistigo/list-document-format` in the plugin API types file (or a re-exported type alias is used)
- [ ] Existing plugins (Sentry, PostHog, user plugin) still typecheck correctly — they don't use the new fields, so this is additive
- [ ] `pnpm nx run artifact-plugin-api:typecheck` passes

## Technical Details

**Files to modify:**
- `packages/artifact-plugin-api/src/types.ts`

**New fields to add to `AlistigoPlugin`:**
```typescript
/**
 * Domain-contribution fields — for plugins that extend the list element model.
 * Only meaningful when the host artifact explicitly calls these.
 */

/** The key this plugin uses under alistigo:metadatas on each list element. */
metadataKey?: string;

/** JSON schema fragment describing this plugin's metadata shape (documentation/validation). */
metadataSchema?: unknown;

/**
 * Pure reducer: given current per-element metadata and a new event, return updated metadata.
 * Called by the host for every event in the log to build per-element plugin state.
 */
reduce?: (
  elementMetadata: Record<string, unknown>,
  event: AlistigoEventRecord,
) => Record<string, unknown>;

/**
 * Renders UI at the leading edge of a list element (e.g. a checkbox).
 * Called once per element. Must not import anything from the host package.
 */
renderListElementLeading?: (
  elementId: string,
  metadata: Record<string, unknown>,
  onCommand: (name: string, payload: unknown) => void,
) => ReactNode;
```

**Import:** `AlistigoEventRecord` needs to be imported from `@alistigo/list-document-format`. Check if this package is already a dependency of `artifact-plugin-api` — if not, add it to `package.json` dependencies as `workspace:*`.

**Remove:** The following fields from `AlistigoPlugin` (they are stubs, nothing reads them):
```typescript
// REMOVE these:
dataShape?: unknown;
render?: unknown;
commands?: Record<string, (...args: unknown[]) => unknown>;
events?: Record<string, unknown>;
```

After removing, check all usages with `grep -r "dataShape\|\.render\b\|\.commands\b\|\.events\b" packages/` to confirm nothing reads them.
