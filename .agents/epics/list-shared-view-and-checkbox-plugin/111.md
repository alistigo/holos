## Technical Details

**Reference:** Look at `packages/list-features/features/artifact-plugins/user-identity-persist.feature` and `user-identity-display.feature` as models for style.

**Required scenarios:**

```gherkin
Feature: Checkbox Plugin
  As a user with the checkbox plugin active
  I want to mark list elements as checked or unchecked
  So that I can track which items are done

  Background:
    Given the checkbox plugin is active
    And a list with elements:
      | name        |
      | Buy bread   |
      | Call mom    |
      | Email Alice |

  @capability:checkbox @actor:user
  Scenario: Check an element and reload — stays checked
    When I check "Buy bread"
    And I reload the list
    Then "Buy bread" is checked
    And "Call mom" is unchecked
    And "Email Alice" is unchecked

  @capability:checkbox @actor:user
  Scenario: Uncheck a checked element and reload — stays unchecked
    Given "Buy bread" is checked
    When I uncheck "Buy bread"
    And I reload the list
    Then "Buy bread" is unchecked

  @capability:checkbox @actor:user
  Scenario: Checking one element does not affect others
    When I check "Buy bread"
    Then "Call mom" is unchecked
    And "Email Alice" is unchecked

  @capability:checkbox @actor:user
  Scenario: All elements start unchecked on a new list
    Then each element is unchecked
```

**Step language rules** (follow project Gherkin conventions from `.agents/skills/gherkin-features/`):
- Use `I check "<name>"` not `I click the checkbox for element "<name>"`
- Use `"<name>" is checked` not `the element named "<name>" has a checked checkbox`
- Use headerless tables for element collections
- The reload step is `I reload the list` (not `I close and reopen the browser`)

**Glossary additions** (if `packages/list-features/features/GLOSSARY.md` or similar exists):
- **Checkbox Plugin** — A domain-contribution plugin that adds a checked/unchecked state to each list element, stored under `metadatas.checkbox.selected` in the list document.
- **Checked state** — A boolean `selected: true` stored in `alistigo:metadatas["checkbox"]` for a list element, derived by replaying `ListElementChecked` events.
