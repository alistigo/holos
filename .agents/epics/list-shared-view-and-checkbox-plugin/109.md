# Task: ListView UI — Attribution + Plugin Zones + Stories

## Description

All `list-components-react` UI changes for both features in one task (to avoid merge conflicts). This is the single task that owns `ListView.tsx` and `ListView.stories.tsx`.

**Shared-list view:** Conditionally show avatar + pseudo + relative date below each element.
**Plugin zones:** Add a `renderListElementLeading` slot per element that plugins can populate (e.g., checkbox).

## Acceptance Criteria

### Shared-list view UI
- [ ] `ListView` accepts an optional `actors?: AlistigoActorRecord[]` prop
- [ ] When `actors` contains ≥2 entries, an attribution row is rendered below each element that has attribution data
- [ ] Attribution row shows: avatar (circular `<img>` from base64 data URL), pseudo, relative date ("3 hours ago", "yesterday") using `date-fns` `formatDistanceToNow`
- [ ] Attribution row is hidden completely when `actors.length < 2` (no DOM nodes, no whitespace)
- [ ] Attribution data comes from the `AlistigoProjection` item's `alistigo:attribution?` field (set by the projection layer in task 003)

### Plugin zones
- [ ] `ListView` accepts an optional `plugins?: AlistigoPlugin[]` prop
- [ ] For each list element, the host calls `plugin.reduce()` across the full event log to build per-element metadata — pass `events` (from the AlistigoProjection or document) to ListView
- [ ] `ListView` calls `plugin.renderListElementLeading?.(elementId, pluginMeta, onCommand)` and renders the result in a leading slot before the element name
- [ ] `onCommand` is wired to a prop `onPluginCommand?: (pluginName: string, commandName: string, payload: unknown) => void`

### Stories
- [ ] `ListView.stories.tsx` has new exported stories:
  - `MultiActorSharedView` — 3 items, 2 different actors, shows attribution on all items
  - `SingleActorNoAttribution` — 3 items, 1 actor, no attribution shown
  - `WithCheckboxPlugin` — 3 items, checkbox plugin active, all unchecked
  - `WithCheckboxPluginChecked` — 3 items, one item checked
  - `MultiActorWithCheckbox` — 3 items, 2 actors, attribution + checkbox combined

## Technical Details

**ListView props signature (extend existing):**
```typescript
interface ListViewProps {
  projection: AlistigoProjection;
  onDelete: (elementId: string) => void;
  // New:
  actors?: AlistigoActorRecord[];
  plugins?: AlistigoPlugin[];
  onPluginCommand?: (pluginName: string, commandName: string, payload: unknown) => void;
  // For plugin reduce calls — the raw event log to replay:
  events?: AlistigoEventRecord[];
}
```

**Per-element metadata building (inside ListView):**
```typescript
function buildElementMetadata(
  elementId: string,
  events: AlistigoEventRecord[],
  plugin: AlistigoPlugin,
): Record<string, unknown> {
  let meta: Record<string, unknown> = {};
  for (const event of events) {
    meta = plugin.reduce?.(elementId, meta, event) ?? meta;
  }
  return meta;
}
```

**Leading slot rendering:**
```typescript
{plugins?.map(plugin =>
  plugin.renderListElementLeading?.(
    elementId,
    buildElementMetadata(elementId, events ?? [], plugin),
    (name, payload) => onPluginCommand?.(plugin.name, name, payload),
  )
)}
```

**Attribution row component:**
```typescript
function AttributionRow({ attribution }: { attribution: AlistigoItemAttribution }) {
  const relative = formatDistanceToNow(new Date(attribution.addedAt), { addSuffix: true });
  return (
    <div className="flex items-center gap-1 text-xs text-muted-foreground mt-0.5">
      <img src={attribution.avatar} alt={attribution.pseudo} className="w-4 h-4 rounded-full" />
      <span>{attribution.pseudo}</span>
      <span>·</span>
      <span>{relative}</span>
    </div>
  );
}
```

**For stories:** Import `checkboxPlugin` from `@alistigo/artifact-checkbox-plugin` in the stories file. Build mock event logs with `ListElementChecked` events to demonstrate checked state.

**Note on `events` prop:** The projection alone doesn't contain the raw event log. The ListView needs the event log to call `plugin.reduce()`. Add `events?: AlistigoEventRecord[]` to the projection type or pass it as a separate prop. Prefer a separate prop to keep the projection pure.
