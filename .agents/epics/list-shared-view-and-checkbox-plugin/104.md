- `packages/list-document-format/src/serializer/list-document-serializer.ts`

**New types:**
```typescript
export interface AlistigoActorRecord {
  "alistigo:actorId": TypeIDString;
  "alistigo:userId": string;
  "alistigo:pseudo": string;
  "alistigo:avatar": string; // base64 data URL
}

export interface AlistigoPluginRecord {
  name: string;
  version?: string;
  config?: Record<string, unknown>;
}

export interface AlistigoListElementCheckedRecord extends AlistigoEventRecordBase {
  "alistigo:eventType": "ListElementChecked";
  "alistigo:listElementId": TypeIDString;
  checked: boolean;
}
```

**Serializer signature change:**
```typescript
export interface SerializeOptions {
  actorsById?: Map<string, AlistigoActorRecord>;
}

serialize(list: List, previousDocument?: AlistigoDocument, options?: SerializeOptions): AlistigoDocument
```

When `options.actorsById` is provided, merge into `alistigo:actors` array (upsert by actorId). Preserve existing actors from `previousDocument` that are not in the new map.

**JSON schema additions:**
- Add `"alistigo:actors"` as optional array of ActorRecord objects to the document schema
- Add `"alistigo:metadatas"` as optional additionalProperties object to ListItem
- Add `"alistigo:plugins"` as optional array of PluginRecord objects
- Add `"ListElementChecked"` to the eventType enum
- `ListElementChecked` requires `"alistigo:listElementId"` and `"checked"` (boolean)

**Note on `AlistigoListElementCheckedRecord` in serializer:**
The `recordToEvent` and `eventToRecord` functions in the serializer are list-domain-aware. For now, `ListElementChecked` events are stored verbatim in the event log — the serializer needs to handle them as pass-through records since the list-domain aggregate does not yet know about them (they are plugin-owned events). Add a `| AlistigoListElementCheckedRecord` pass-through case.
