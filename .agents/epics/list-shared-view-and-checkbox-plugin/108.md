# Task: artifact-checkbox-plugin — New Package

## Description

Create the first domain-contribution plugin for the list artifact. The package is scaffolded with `scripts/new-package.sh`, then populated with:
- Domain: reducer + command creator
- Plugin: AlistigoPlugin implementation
- UI: Checkbox React component
- Storybook: stories with all visual states

## Technical Details

**Scaffold:**
```bash
bash scripts/new-package.sh artifact-checkbox-plugin
```
Then set package name to `@alistigo/artifact-checkbox-plugin` in `package.json`.

**Reducer implementation:**
```typescript
// src/reducer.ts
import type { AlistigoEventRecord } from "@alistigo/list-document-format";

export interface CheckboxMetadata {
  selected: boolean;
}

export function checkboxReducer(
  meta: Record<string, unknown>,
  event: AlistigoEventRecord,
): Record<string, unknown> {
  if (
    event["alistigo:eventType"] === "ListElementChecked" &&
    event["alistigo:listElementId"] === /* current elementId — passed via closure or context */
  ) {
    return { selected: (event as AlistigoListElementCheckedRecord).checked };
  }
  return meta;
}
```

Note: the `reduce()` function receives the element's current metadata and one event. The host calls it for all events and for each element separately. So the reducer signature is `(meta, event) => meta` — it doesn't need to filter by elementId internally if the host passes per-element events. **Check how the host will call it** (task 007 decision) and align.

Actually, the host will call `plugin.reduce(currentMeta, event)` for every event across the full event log for every element. So the reducer MUST check whether `event["alistigo:listElementId"] === elementId`. But it doesn't receive `elementId` directly. Two options:

Option A: The host calls `plugin.reduce(elementId, currentMeta, event)` — change the signature.
Option B: The reducer checks `event["alistigo:listElementId"]` and the host passes which element ID to match.

Go with Option A: change `reduce()` signature to `(elementId: string, elementMetadata: Record<string, unknown>, event: AlistigoEventRecord) => Record<string, unknown>`. Update `artifact-plugin-api/src/types.ts` accordingly (task 005 may need a note or this task corrects it).

**Command creator:**
```typescript
// src/command.ts
import type { AlistigoListElementCheckedRecord } from "@alistigo/list-document-format";

export function createCheckListElementEvent(
  elementId: string,
  actorId: string,
  listId: string,
  checked: boolean,
): AlistigoListElementCheckedRecord {
  return {
    "alistigo:listEventId": /* generate a new TypeID */,
    "alistigo:eventType": "ListElementChecked",
    "alistigo:listId": listId,
    "alistigo:listElementId": elementId,
    "alistigo:actorId": actorId,
    "alistigo:timestamp": new Date().toISOString(),
    checked,
  };
}
```

Use the same TypeID generation utility as the rest of the codebase (check `packages/list-domain/src/value-objects/` for the ID generation pattern).

**Plugin export:**
```typescript
// src/index.ts
const checkboxPlugin: AlistigoPlugin = {
  name: "@alistigo/artifact-checkbox-plugin",
  version: pkg.version,
  type: "list-element",
  metadataKey: "checkbox",
  metadataSchema: { type: "object", properties: { selected: { type: "boolean" } } },
  reduce: checkboxReducer,
  renderListElementLeading: (elementId, metadata, onCommand) =>
    createElement(CheckboxLeading, { elementId, metadata, onCommand }),
};

export default checkboxPlugin;
export { createCheckListElementEvent };
```

**JSON schema fragment:** Export a `checkboxMetadataSchema` object describing the plugin's metadata shape. It will be used by `metadataSchema` and could later be composed into the main document schema.
