AI Draw Comments Demo

This page demonstrates the @alistigo/artifact-ai-draw-comments widget. The "Draw Comment" button appears above — click it to start an annotation session.

Note: sending to Claude requires a Claude artifact iframe context (window.claude). In this standalone demo, the send step will show an error since window.claude is not available.
